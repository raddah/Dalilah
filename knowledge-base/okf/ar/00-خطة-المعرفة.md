# الهدف

حفظ المعرفة التراثية بصيغة Markdown قابلة للمراجعة والإصدار، ثم إسقاط بيانات المصادر والعلاقات إلى D1، وإضافة الوسائط إلى R2 فقط بعد التحقق من الحقوق.

## سياسة الإجابة

تستخدم دليلة الأدلة المسترجعة فقط، وتعرض عنوان المصدر ورابطه، وتحافظ على لغة المستخدم، وتصرح بعدم كفاية الأدلة عند الحاجة. لا تُخترع المواقع أو التواريخ أو أوقات الزيارة أو الروابط أو حقوق الصور.
