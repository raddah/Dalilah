# Purpose

Maintain a human-readable, versioned knowledge layer that can be reviewed in GitHub and projected into D1, R2, and later Vectorize indexes.

## Workflow

1. Register a specific trusted page.
2. Create one focused card per topic.
3. Record only claims supported by that page.
4. Review metadata, freshness, language, and licensing.
5. Project source metadata into D1.
6. Add media only when the source and license permit storage in R2.
7. Re-verify changing sources according to their `stale_after` date.

## Answer policy

Dalilah must use retrieved evidence for factual claims, return citations, match the user's language, and state when evidence is insufficient. It must never invent locations, dates, hours, URLs, or image credits.
